# The Mystery Wi-Fi

14 supplied pages including cover and lesson, with matching portrait and landscape artwork. Source: The Mystery WiFi.zip, story_01 through story_14 in original order.

Each supplied image was edited with built-in image generation using dist/assets/library-watercolour.webp as palette/brushwork reference only. Prompt preserves exact composition, characters, dialogue, board text and captions. Soft translucent watercolor on ivory paper, muted sage, powder blue, blush pink, pale wood and gentle yellow. Reduced orange/sepia saturation and embossed texture. Crisp readable text; no cropping, omissions or new characters. Lesson uses a soft botanical watercolor border and butterflies with all lesson text intact.

WebP assets: dist/reader/assets/mystery-wifi/story_01.webp through story_14.webp and matching _landscape.webp. Portrait 887×1774; landscape 1536×1024. Shared navigation, restart, bookmarks and responsive orientation selection. No narration.
